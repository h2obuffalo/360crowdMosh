# Roadmap

Implemented: explicit geometry modes, file/device/stream sources, continuous source-space analysis, pixel-accurate seam-aware masks, flash suppression, confidence/hysteresis/cooldown selection, time-based flat and spherical controllers, diagnostics, timestamp output resampling, synthetic tests, packaging, and CI.

Next focused work: tune thresholds with representative dim/strobe venue footage; add a small mask-authoring helper; benchmark 4K flat and equirectangular input on the target M1; improve long-running stream reconnect policy.

Deferred: YOLO/person detection, faces or identity, cloud video services, bundled RTMP server, heavy GPU frameworks, and general VJ controls.
